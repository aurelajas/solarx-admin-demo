# SolarX — Admin panel demo

Interactive, static demo of the SolarX management console, hosted on GitHub Pages.

**Live:** https://aurelajas.github.io/solarx-admin-demo/

- Opens signed in as the super admin, on the dashboard.
- Everything works against sample data: orders (status changes, tracking), customers, products (editing, photos, publishing), deals, coupons, installation projects, blog editor, reviews and comment moderation, users and permissions, audit log, email outbox, payment and calculator settings.
- Available in English, Albanian and German (SQ / EN / DE switch).
- No backend: every request is answered in the browser. Edits are kept in your browser only — use **Demo → Reset demo data** to start over.

Storefront demo: https://aurelajas.github.io/solarx-store-demo/
